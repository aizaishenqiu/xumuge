## 中文

### 这是什么

五个 **公开 demoware** 岗位，以 agentskills 风格的 `SKILL.md` 发布，可免费导入虚募阁桌面端做流程演示。

- **不是** 商业全量岗位包  
- **不是** 从私有 `role-packs-src` 拷贝的正文  
- 目录名与私有 demo SKU 的 slug **对齐**，仅方便对照

### 如何导入（桌面端）

1. 打开虚募阁桌面端 → 设置中的用户技能 / 技能目录（或文档目录下的「虚募阁技能」文件夹）。  
2. 将本目录下任一子文件夹（含 `SKILL.md`）复制进去，或按产品 UI「导入 Skill」选择该文件。  
3. 在对话中点名对应角色或技能名试用。  

具体菜单文案以当前客户端版本为准；本 README 不替代产品帮助。

## English

### What

Five **public demoware** roles shipped as agentskills-style `SKILL.md` files for free import into the Virmoor desktop app.

They are **not** commercial packs and **not** copies of private role sources. Folder names match private demo SKU slugs for reference only.

### Import

Copy a skill folder (with `SKILL.md`) into the app’s user-skills directory, or use the in-app import action. Exact UI labels depend on the client build.

### License

Apache-2.0 with the rest of this staging tree. Full commercial role assets remain closed — see [OPEN_SOURCE.md](../OPEN_SOURCE.md).
