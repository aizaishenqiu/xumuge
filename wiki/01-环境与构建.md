# 01 · 环境与构建

QQ 群：`1102740387`

## 1. 前置依赖

| 组件 | 说明 |
|------|------|
| Node.js | 建议 LTS（18+ / 20+） |
| pnpm | 本仓库标准包管理器（`packageManager` / lockfile 为 pnpm） |
| Rust | stable；配合 [Tauri 2](https://v2.tauri.app/) |
| Windows | WebView2 Runtime；MSVC 构建工具链 |
| 可选 | Playwright Chromium（`pnpm setup:qa`，UI 验收） |

检查：

```bash
node -v
pnpm -v
rustc -V
cargo -V
```

## 2. 克隆与安装

```bash
git clone https://gitee.com/jiukakeji/xumuge.git
cd xumuge/xu-desktop
cp .env.example .env.development
# 编辑 .env.development：账号 API、模型相关等；勿提交真实密钥
pnpm i
```

`postinstall` 会跑 `scripts/patch-foucui-h.mjs`（修补 foucui 相关兼容）。

## 3. 本地开发

```bash
pnpm tauri:dev
```

等价于：`tauri dev --features native-tts,devtools`。

- 前端：Vite + Vue 3  
- 壳：Tauri 2（Rust）  
- 默认开发前端端口见 `tauri.conf.json` / Vite 配置（常见 `1420`）  

仅起前端（不启桌面壳，能力残缺）：

```bash
pnpm dev
```

停止占用端口（Windows）：

```bash
pnpm dev:stop
```

## 4. 类型检查与单测

## 5. 开源安装包（未签名）

```bash
pnpm build:release:oss-unsigned
```

流程概要：

1. 编译演示岗包 → `resources/role-packs/full.zh-CN.xupack`（gitignore）  
2. `guard-release-bundle`  
3. 写入无证书指纹的 `tauri.windows.conf.json`  
4. `prepare-release-clean`  
5. `pnpm exec tauri build` → NSIS `*-setup.exe`  

产物勿提交 git。正式对外签名包不在本文范围。

## 6. 仅编译岗包
