## 1. 目录速查

| 目录 / 文件 | 职责 |
|-------------|------|
| `main.ts` / `App.vue` | 入口与根组件 |
| `router/index.ts` | 路由、登录守卫、过期跳转 |
| `pages/` | 路由级页面（Home、Office、Settings…） |
| `components/` | 可复用组件（chat、office、canvas、settings…） |
| `stores/` | Pinia 状态 |
| `utils/` | 工具：`request.ts`、`auth.ts`、`appEnv.ts`、语音、工作区等 |
| `agent/` | 与智能体/执行相关的前端逻辑（若存在） |
| `intent/` | Brief / 澄清 / 文案脚手架等意图编排 |
| `office/` | 办公室、岗位 API 封装（如 `rolePackApi.ts`、`agencyRoles.ts`） |
| `canvas/` | 草图引擎、流程图、导出 |
| `help/` | `helpManifest.ts`（开源树可能为空树，产品帮助走官网） |
| `brand` / 主题 | 外观与启动主题脚本配合 `public/theme-boot.js` |

## 2. 关键约定

1. **端点只从 `utils/appEnv.ts` 读**（`VITE_*`），业务页禁止写死生产 URL。  
2. **云 API 只走 `utils/request.ts`**，禁止页面裸 `fetch` 调账号服。  
3. 成功响应约定：`code === 0`。  
4. Token：`access_token` + `refresh_token`（下划线）；过期先 refresh 再清登录。  
5. 用户可见错误：`fouAlert`。  

## 3. 主对话与闸门

首页 `/home`（`HomePage` / `ChatPage` 相关组件）承载：

- 问询 / 计划 / 智能体 / 漏洞等模式  
- 岗位专家选择、附件、截图、语音入口  
- 与工作区、审批写盘联动（经 Tauri 命令与前端门禁）  

具体交互以产品帮助与源码 `components/chat/*` 为准。

## 4. 扩展新页面（建议步骤）

1. 在 `pages/` 新增 `.vue`（含文件头注释：`@file` `@author` `@date` `@version` `@category` `@algo`）。  
2. 在 `router/index.ts` 注册路由；需登录则走默认守卫。  
3. 若调云 API：封装在 `utils` 或 `office` 层，内部用 `request`。  
4. 设置项放入 `pages/SettingsPage.vue` 对应分组组件。
