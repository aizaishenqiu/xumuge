## 3. 技术栈（摘要）

| 层 | 技术 |
|----|------|
| UI | Vue 3、foucui、Pinia（stores）、Vue Router（hash） |
| 构建 | Vite、pnpm、vue-tsc |
| 桌面 | Tauri 2、`@tauri-apps/api` / plugin-fs / dialog / shell |
| 编辑器 | CodeMirror 6、xterm |
| 画板 | 自研 sketchEngine、@vue-flow/core |
| 云 API | `src/utils/request.ts`（fetch + 刷新队列；成功 `code===0`；错误 `fouAlert`） |

## 4. package.json 常用脚本

| 脚本 | 用途 |
|------|------|
| `pnpm tauri:dev` | 桌面开发 |
| `pnpm build` | 仅前端 dist + guard |
| `pnpm build:release:oss-unsigned` | 开源未签名安装包 |
| `pnpm build:role-pack:full` | 编译 zh-virmoon → full.zh-CN.xupack |
| `pnpm typecheck` / `pnpm test` | 检查与脚本单测 |
| `pnpm setup:rg` | 拉取 rg sidecar |

## 5. UI 约定（开源树同样遵守）

- 主 UI 库：**foucui**（`npm` 包，非 workspace 链本地）  
- 用户错误用 **`fouAlert`**，避免 toast / 裸 URL  
- 按钮需带 icon（Remix 名）  
- 有数据业务页：顶栏工具+搜索，下部左分类（可无）+ 右表格，页面 margin 约 20px
