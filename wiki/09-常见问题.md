# 09 · 常见问题

QQ 群：`1102740387`（加群注明：开源开发）

## 1. 缺少 rg.exe

报错指向 `src-tauri/bin/rg.exe`：

```bash
cd xu-desktop
pnpm setup:rg
```

## 2. cargo / build-script「拒绝访问」

部分环境对 `opensource/.../src-tauri/target` 写权限异常。可指定可写目录：

```powershell
$env:CARGO_TARGET_DIR="D:\cargo-targets\xu-desktop"
pnpm build:release:oss-unsigned
```

## 3. `tauri` 命令找不到

用：

```bash
pnpm exec tauri build
```

开源脚本 `build-release-oss-unsigned.mjs` 已按此调用。

## 4. 岗包为空 / 岗位库无数据

1. 确认存在 `role-packs-src/zh-virmoon`  
2. 执行 `pnpm build:role-pack:full`  
3. 重启应用并在设置中确认数据包已加载  

## 5. 登录失败

1. `.env.development` 中 `VITE_XU_ACCOUNT_URL` 是否指向可用 `/api/v1`  
2. 服务是否返回 `access_token` + `refresh_token`  
3. 看 `fouAlert` 文案，勿只看 Network 裸 URL  

## 6. 包管理器

请用 **pnpm**。混用 npm/yarn 易导致 lockfile 与 `postinstall` 不一致。
