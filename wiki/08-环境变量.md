# 08 · 环境变量

QQ 群：`1102740387`

模板：`xu-desktop/.env.example`  
本地：复制为 `.env.development` / `.env.production`（勿提交密钥）。

## 1. 规则

| 前缀 | 谁读 |
|------|------|
| `VITE_*` | Vite 打包进前端 |
| `XU_*` | Tauri/Rust 启动加载（已存在的系统环境变量通常不覆盖） |

改 env 后需重启 `pnpm tauri:dev`。

## 2. 常用项（开源示例为占位域名）

```bash
VITE_XU_STORE_URL=https://xxx.com/download
VITE_XU_DOWNLOAD_PAGE_URL=https://xxx.com/download
VITE_XU_DESKTOP_UPDATE_SLUG=virmoor-desktop-windows

# VITE_XU_ACCOUNT_URL=http://127.0.0.1:8080/api/v1
# VITE_XU_LICENSE_URL=http://127.0.0.1:8080/api/v1
# VITE_XU_ACCOUNT_URL=https://api.xxx.com/api/v1

VITE_XU_VOICE_PACK_CATALOG_URL=https://api.xxx.com/uploads/voice-packs/catalog.json
VITE_XU_COSY_FASTAPI_URL=http://127.0.0.1:50000
VITE_XU_LOCAL_BRAIN_URL=http://127.0.0.1:8787/v1
```

业务代码通过 `src/utils/appEnv.ts` 读取，不要在页面硬编码。
