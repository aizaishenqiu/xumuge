# 07 · 岗位包构建

## 1. 源码位置

```
xu-desktop/role-packs-src/zh-virmoon/
├── manifest.yaml
├── finance/*.md
├── engineering/*.md
└── …（多行业目录）
```

每个岗位一般为带 YAML frontmatter 的 Markdown。开源仓内约 **461** 个演示岗。

分类数据：`docs/config/taxonomy-industries.json`、`taxonomy-positions.json`。

## 2. 编译为 .xupack

```bash
cd xu-desktop
pnpm build:role-pack:full
```

实际命令（见 `package.json`）：

```text
node scripts/build-role-pack.mjs
  --locale zh-virmoon
  --all --demo
  --pack-id virmoor-roles-demo-zh-virmoon
  --content-version 2026.09.1
  --skip-quality-gate
  --out resources/role-packs/full.zh-CN.xupack
```

说明：

- 输出文件名固定为 `full.zh-CN.xupack`，以满足 Tauri `bundle.resources` 与 `guard-release-bundle`。  
- 二进制 **gitignore**，勿提交。  
- `--demo` 表示演示包标志；内容来自本仓 `zh-virmoon` 源。  

## 3. 与安装包的关系

`pnpm build:release:oss-unsigned` 会先执行 `build:role-pack:full`，再打 NSIS。

## 4. 运行时加载

Rust `role_pack` 模块与前端 `office/rolePackApi.ts`、`agencyRoles.ts` 等配合加载已安装包。调试岗位列表：打开 `/agency` 或对话底栏选专家。

## 5. 轻量 Skill

`demo-skills/*/SKILL.md` 可导入用户技能目录，与全量岗包是两条线；主演示内容仍以 `zh-virmoon` 为准。
