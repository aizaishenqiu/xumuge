## 2. 项目介绍

虚募阁是面向**本地工作流**的 AI 智能体桌面客户端。设计核心：

**不让 AI 随意改动你的本地文件——写盘必须经用户弹窗批准。**

### 三道工作闸门

| 闸门 | 作用 |
|------|------|
| **问询 Inquiry** | 只回答问题，不启用写盘工具；适合咨询与评估可行性 |
| **计划 Plan** | 输出步骤、风险、验收标准；只推演，不执行、不改文件 |
| **智能体 Agent** | 实际执行；修改文件前弹出对话框等待用户同意（不是终端输入 Y） |

另有只读向的「漏洞」诊断模式、多任务并行，以及按措辞自动分流（提问 / 澄清 / 短规划 / 授权动手）等能力（见下文）。

网页官网仅作展示大厅。截图、语音、本地读写、审批闸门等**仅在桌面端完整实现**。

推荐流程：**问询 → 计划 → 智能体**。不要跳过计划直接让智能体改文件。

## 3. 详细功能介绍

### 3.1 账号、启动与帮助

- **云账号登录** — 启动登录；官网注册后可在桌面端使用同一账号（需配置账号服务）。  
- **新手引导** — 首次启动配置「三脑」等基础项。  
- **应用内帮助** — 按模块浏览帮助文档。  
- **检查更新 / 问题反馈** — 独立更新窗口；登录后可上报问题。  

### 3.2 主对话与三闸门（首页）

- **问询 / 计划 / 智能体 / 漏洞** — 能力逐级开放；智能体写盘须审批。  
- **多任务** — 多会话并行，各会话独立排队。  
- **自动分流** — 按措辞区分直答、澄清、短规划、授权动手。  
- **岗位专家** — 从岗位库选择人设，注入风格与三脑槽位。  
- **默认权限 / 完全访问** — 沙箱逐次审批，或信任模式下跳过审批。  
- **三脑模型** — 指挥脑 / 工作脑 / 代码脑；本地与远程；仅显示测通成功的模型。  
- **上下文压缩** — Token 用量提示，可压缩长对话。  
- **补丁审查** — 行级 diff 预览，写盘前审批，可撤销本批。  
- **附件 / 记住 / 截图** — 对话附件；写入本机记忆；区域截图挂到对话。  
- **单窗首页 + 按需 IDE** — 首页以对话为主，需要时打开全屏内置 IDE。  

### 3.3 内置 IDE 与编码辅助

- **虚募阁 IDE** — 编辑器、终端、文件树、活动栏。  
- **编码驾驶** — 可联动本机 Cursor / VS Code 等 CLI。  
- **Playwright QA** — 界面验收自动化（需安装 Chromium）。  
- **高级执行策略 / 软件自动驾驶** — 实验性能力，默认需谨慎开启并审批。  

### 3.4 Canvas 画板

- **矢量草图** — 画笔、几何、文字、图层、对齐；导出 PNG / PDF / SVG / DXF 等。  
- **对话指挥画图** — 用对话驱动户型、海报、排版等草图。  
- **流程图 / 甘特 / 图册** — 多页流程、文本预览时间条、素材插入。  

### 3.5 语音

- **语音通话** — 全屏连续通话与字幕；可配合工具（须工作目录与确认策略）。  
- **语音输入 / 唤醒** — 一句写入输入框；唤醒词进入通话。  
- **多引擎 TTS** — 系统 / 离线 Kokoro / CosyVoice 等；可安装外部语音包。  

### 3.6 项目与办公室

- **项目总览** — 按行业筛选的工作单元；文档路径与生成路径分离。  
- **项目队列 / 行业流程** — 顺序结项；按行业标准派活流水线。  
- **3D AI 办公室** — 大厅、工位状态、Boss 协作条；可沉浸全屏。  
- **需求澄清 Brief / 全员开工** — 立项问答后按波次派活（规划→设计→开发→测试等）。  
- **设计预览、中途转向、上线安全清单** — 拍板后再开发；运行中调整；软件结项门禁。  

### 3.7 团队、监控与往来

- **AI 团队** — 花名册：岗位、工位、三脑槽、工作区。  
- **在岗监控** — 派活队列、进度、补派/取消；交付争议处理。  
- **员工往来** — 员工间私信与会话旁听。  

### 3.8 岗位库与数据包

- **岗位库** — 分类树 + 搜索；开源演示约 **461** 岗（`zh-virmoon`）。  
- **岗位数据包 `.xupack`** — 安装 / 导入 / 版本查看（商业全量包另购，不在本仓）。  
- **自定义岗位 / 用户技能** — 自建人设与 `SKILL.md`。  

### 3.9 记忆、MCP 与连接

- **记忆库** — Markdown 记忆，对话与派活时可检索；「越用越懂我」沉淀。  
- **MCP** — 配置本机扩展工具；含 Blender / 3ds Max 等三维宿主脚本能力（须授权）。  
- **飞书 / 企微** — 群内派活、出站通知、实验性客服同步等（默认谨慎写盘）。  

### 3.10 设置与其它

设置中心含：公司与外观、三脑、账单与用量、执行并发、协作护栏、隐私、安全审计、许可证、快捷键、个人中心、法律协议等。  
另有组件市场（`.xucap`）、商业重组件（`.foubiz`，须许可证）、半自动获客说明等。

## 5. 开发者构建（pnpm）

本仓库使用 **pnpm**（不是 npm）。工程在 `xu-desktop/`。

```bash
git clone https://gitee.com/jiukakeji/xumuge.git
cd xumuge/xu-desktop
cp .env.example .env.development
pnpm i
pnpm tauri:dev
pnpm build:release:oss-unsigned
```
