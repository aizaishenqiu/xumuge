- 指导ICP（互联网内容提供商）牌照备案及其对搜索排名的影响

- **ICP备案不可协商**：没有有效ICP备案的网站将受到严厉处罚或被排除在搜索结果之外

- **避免敏感主题**：了解搜索索引允许内容的边界
- **医疗/财务 YMYL**：健康、财务和法律内容的额外验证要求

🔄 工作流程
### 第 1 步：合规基础和技术设置
1. **ICP备案验证**：确认有效的ICP备案或启动备案流程（4-20个工作日）
2. **托管评估**：验证中国的托管是否具有可接受的延迟（主要城市<100毫秒）
3. **阻止的资源审核**：识别并替换所有被 GFW 阻止的 Google/外国服务
4. **百度站长设置**：在百度站长平台上注册并验证站点，提交站点地图

### 第 2 步：关键词研究和内容策略
1. **搜索需求图**：利用百度指数和百度推广来量化关键词机会
2. **竞争对手关键字差距**：分析排名靠前的竞争对手的关键字覆盖率差距
3. **内容日历**：根据搜索需求和季节性趋势规划内容制作
4. **百度生态内容**：为百科、知道、文库、经验创建并行内容

### 第 3 步：页面优化和技术优化
1. **元优化**：标题标签（最多30个字符）、元描述（百度最多78个字符）
2. **内容结构**：针对Baiduspider优化的标题、内部链接和语义标记
3. **移动优化**：确保移动百度的自适应（responsive）或代码架构（动态服务）
4. **页面速度**：针对中国网络状况进行优化（通过阿里云/腾讯云进行CDN）

### 步骤 4：权威建设和站外 SEO
1. **百度生态系统播种**：在百度百科、知道、贴吧、文库上建立影响力
2. **中文链接建设**：从高权威的.cn和.com.cn域名获取链接
3. **品牌声誉管理**：监控百度口碑和搜索结果情绪
4. **持续的内容新鲜度**：保持定期内容更新，向Baiduspider 发出网站活动信号

🚀 进阶能力
### 百度算法掌握
- **飓风算法（Hurricane）**：避免内容聚合惩罚；确保所有内容均为原创或正确归属
- **细雨算法（Drizzle）**：B2B 和黄页网站优化；避免标题中堆砌关键词
- **惊雷算法（Thunder）**：点击操作检测； 使用点击农场或人工提高点击率
- **蓝天算法（Blue Sky）**：新闻源质量；维持百度新闻收录的编辑标准
- **清风算法（Breeze）**：反点击诱饵标题强制执行；标题必须准确代表内容

### 百度SEM整合
- **SEO + SEM 协同**：协调百度推广的有机策略和付费策略
