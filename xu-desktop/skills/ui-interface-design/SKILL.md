# 界面设计 Skill

> 先定气质与令牌，再选框架写页面。没有品牌一句、没有首屏构图，禁止写界面代码。

## 何时使用

- 新建或改版 Web、后台、营销落地页、工具编辑器、桌面窗口界面
- 任务含：界面、页面、组件、主题、布局、美观、前端 UI、登录/首页

本 Skill **不是** AI 产品交互专项（那是另一套「AI 界面设计」）。这里只管**看起来像正经产品**。

## 开工顺序（禁止跳步）

1. **产品类型**（只选一类）：营销落地 / B 端后台 / 工具编辑器 / 电商 / 内容阅读
2. **品牌一句**：产品名 + 气质词（稳重 / 锐利 / 温暖 / 克制…）。没有气质禁止开写
3. **首屏一构图**：品牌或产品名 + 一句标题 + 一句说明 + 一组 CTA + **一块真实主视觉**。禁止首屏仪表盘、卡片墙、统计条堆砌
4. **设计令牌**：写入 `UI/design-tokens.md`（主色 / 中性 / 语义 / 字号 / 8pt 间距）。页面只用这些变量
5. **框架选定**（见下表）后再生成页面代码

## 反「AI 丑站」硬禁令

- 禁止默认：紫白/紫靛渐变、奶油底+衬线+陶土色、报纸密栏零圆角、无端深色模式
- 禁止：Inter / Roboto / Arial / 纯系统字体当**展示标题**；圆角胶囊堆、多层阴影、emoji 当图标、英雄区贴纸徽章
- 禁止：首屏卡片墙、统计数字条、日程碎片、多段抢戏文案
- 强制：有真实视觉锚点（产品图、场景图、插画）；装饰渐变不算主视觉
- 强制：每一屏/每一段只有一个目的、一个标题
- 交活前自问：**去掉产品名后，是否还像网上随处可见的 AI 模板站？** 是则重做色与字

## 色调与布局

| 类型 | 色调默认 | 布局 |
|------|----------|------|
| B 端后台 | 中性灰底 + **单一**品牌主色；成功/警告/错误只用语义色 | 顶栏工具+搜索；左分类（可无）右表格；内容区边距统一 |
| 营销落地 | 品牌主色主导，少用渐变 | 全出血英雄区；一构图；下滚分节，每节一个目的 |
| 工具/编辑器 | 低饱和；工作区对比高于装饰 | 活动栏 + 侧栏 + 主区；少装饰 |
| 政企/公文感 | 克制蓝或红作点缀，忌花哨 | 清晰层级、大留白、正文高对比 |

字体：中文优先思源黑体或系统黑体阶梯（正文 14–16、标题逐级加大、行高约 1.5）。英文展示字体须有性格，并与中文搭配写进令牌。对比度正文 ≥ 4.5:1。

## UI 框架选型

| 条件 | 推荐 | 禁止 |
|------|------|------|
| 虚募阁桌面/本仓 Vue 产品 | foucui（按钮必须带图标，弹窗用组件库对话框） | Element / Ant / Naive 当主库 |
| 用户软件项目 · Vue3 管理端 | Naive UI 或 Element Plus（国内生态）+ **用令牌覆盖主题** | 多个组件库混用 |
| 用户软件项目 · React | shadcn/ui + Radix + Tailwind，颜色来自令牌 | 无令牌直接堆 Ant 默认蓝 |
| 用户软件项目 · 营销站 | 轻量自研布局 + 少量头组件 | 整站套 Admin 后台皮肤 |
| 技术栈未定 | 先出 `UI/` 线框与令牌，**确认栈后再装 UI 库** | 先安装三套组件库再想设计 |

Brief 或用户已指定框架时，以用户为准，但仍必须套本项目令牌，不得用库默认紫/蓝皮肤交差。

## 交付物

写在项目 `UI/` 下（不要堆在生成根目录）：

1. `UI/README.md`：气质一句、产品类型、框架选择理由
2. `UI/design-tokens.md`：色、字、间距、圆角
3. 关键页线框要点（登录、首页/工作台、列表、空态）

开发岗对照令牌实现；改视觉先改令牌再改页面。

## 交活自检

- [ ] 无重叠、无截断、桌面无意外横向滚动
- [ ] 首屏 3 秒内能看懂「这是什么、我该点哪」
- [ ] 主按钮唯一且明显；加载 / 空 / 错 三态齐全
- [ ] 表单错误贴在字段旁，不是只有顶部一句
- [ ] 可点区域够大；不只靠颜色传达状态
- [ ] 无 TODO / lorem / 「测试」占位漏网
- [ ] 去掉品牌后**不像**任意 AI 模板站
